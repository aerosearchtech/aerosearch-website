# JetBrains Mono

Unmodified WOFF2 files from the official [JetBrains Mono repository](https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts), downloaded on 2026-10-08.

- Regular: weight 400
- Medium: weight 500
- Bold: weight 700

Licensed under the SIL Open Font License 1.1; see `OFL.txt`.

The AIGARM and MSAS layouts load these files through `next/font/local` to avoid a Google Fonts URL parsing failure in the production build.
